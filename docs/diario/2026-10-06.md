## Problemas y soluciones
- **Problema:** el repositorio era privado y Argo CD no podía leerlo.
  **Solución:** escaneo del historial con gitleaks y publicación del repositorio (alternativa
  descartada: deploy key de solo lectura).
- **Problema:** en el commit del `LICENSE` entró también el borrado de `values.yaml`, y el resto
  del trabajo de Argo CD quedó sin commit en una rama ya fusionada.
  **Solución:** mover los cambios pendientes a una rama nueva desde `main` actualizado.
- **Problema:** `podman search` mostraba las versiones en orden alfabético (`v1.9` al final).
  **Solución:** filtrar y ordenar con `sort -V`.
- **Problema:** el bootstrap fallaba con `Apply failed with 1 conflict ... argocd-controller`.
  **Causa:** Argo CD ya se gestionaba a sí mismo y `kubectl` intentaba quitarle la propiedad de sus campos.
  **Solución:** el script solo instala Argo CD si no existe; si existe, lo deja en manos de Argo CD.
- **Problema:** el commit del cierre de la mañana fue directo a `main`, sin PR.
  **Solución:** no se revirtió (solo documentación); se creó el ruleset que obliga a usar PR.
- **Problema:** el nombre de sslip.io no resolvió en el primer intento.
  **Solución:** al reintentar resolvió; era un fallo puntual de DNS.
- **Problema:** `argocd-server` no aplicaba `server.insecure` tras sincronizar.
  **Causa:** ese parámetro solo se lee al arrancar.
  **Solución:** `kubectl -n argocd rollout restart deployment argocd-server` (una sola vez).

## Decisiones
- Repositorio público, sin licencia libre (todos los derechos reservados).
- Argo CD instalado con Kustomize y el manifiesto oficial (sin Helm por ahora).
- `prune: false` en la aplicación de Argo CD (evita que un error en Git lo borre) y `prune: true`
  en las aplicaciones (borrar una carpeta retira la app).
- `ServerSideApply` para Argo CD por el tamaño de sus CRD.
- Componentes de plataforma con una Application que recorre `gitops/platform/` en lugar de un
  ApplicationSet: cada componente declara su propio chart y versión.
- Traefik instalado con Helm (chart oficial con versión fijada); el Traefik integrado de k3s se
  desactiva (`--disable=traefik`) para gestionarlo desde Git.
- Nombres con **sslip.io** de forma provisional: no requieren servidor DNS propio. Riesgo asumido
  para `demo-app`; los servicios con credenciales pasarán a DNS interno con certificado válido.
- Interfaz de Argo CD solo por HTTPS (`websecure`); el TLS lo termina Traefik.
- Criterio de ubicación: lo necesario para recuperar el clúster (acceso, identidad, VPN, copias) va
  fuera de Kubernetes; aplicaciones y servicios de plataforma, dentro.
